# خطة إنتاج فيديوهات الدبلومة (A / B / C)

ثابت في التلاتة: 1080×1920، 30fps، هوية Smarter (عاجي #FBF9F4، كحلي #141C29 / #1E2D44، أخضر #92B43B)، خط Cairo، اللوجو فوق شمال من غير خلفية، كلام الشاشة بيظهر على توقيت الصوت بالظبط، محتوى بين y≈260 و y≈1650، وفي الآخر خانة كومنت بتكتب الكلمة + رد «تفاصيل الدبلومة». مفيش end card لوجو.
الإعلان الحالي بنفسجي غامق بمزيكا بس، فالتلاتة الجداد بالهوية الرسمية وبصوت، وكل واحد بلغة بصرية مختلفة.

## A — «الحاجز» (~40ث) — كلمة «مهتم»

الستايل: قصة بصرية واحدة متصلة. كحلي في الأول، وبيتحول لعاجي لما الحاجز يتكسر.

| الجملة | اللي بيترسم |
|---|---|
| نفسك تستخدم الـ AI باحترافية… حاجز | مستخدم (cursor + كارت شخص) قدام شاشة شات AI، وبينهم لوح زجاج ضبابي، الكلام مش واصل |
| الحاجز ده هيتشال | اللوح يتشرخ ويتكسر على كلمة «هيتشال»، والخلفية تقلب عاجي |
| يبحث معاك، يساعدك تتعلم أسرع | الشات بيرد: بحث بمصادر بتتلم، ملخص بيتبني |
| تعلّمه طريقتك… ينفذ تاسكات مكانك | لوحة «طريقتي في الشغل» بتتملي (أسلوب، تفضيلات)، وبعدها checklist تاسكات بتتعلم ✓ لوحدها |
| فيديوهات وتصميمات… لحد موقعك الخاص | 3 نتايج بتطلع ورا بعض: كارت فيديو، تصميم بوست، صفحة موقع |
| كل حاجة عن الذكاء الاصطناعي التوليدي | كلمة Generative AI كبيرة والنتايج حواليها |
| محاضرات مخصوص، كتيب، متابعة، أسئلتك | قايمة محاضرات + كتيب بيتفتح + فقاعة سؤال عليها رد |
| +300 خريج | رقم 300+ بيعد، ونقط/أفاتارات بتتملي |
| خصم + «مهتم» | شارة خصم + خانة كومنت بتكتب «مهتم» |

## B — «الدليل والمسارات» (~45ث) — كلمة «AI»

الستايل: عاجي ونضيف، بشكل خريطة: مسار أخضر بيترسم بين محطات، والكاميرا بتمشي معاه.

| الجملة | اللي بيترسم |
|---|---|
| شاطر في شغلك… | كارت «انت» عليه شارة خبرة، وبجنبه علامة AI مطفية |
| دليلك في عالم بيتغير كل يوم | أيقونات أدوات بتتغير بسرعة حوالين الكارت، وبوصلة/مسار أخضر بيظهر |
| مهارات ومسارات: جودة أعلى / وقت أقل / تعرض نفسك | 3 محطات على المسار، كل محطة بيتعمل فيها before → after |
| بدل ما تتوه بين الأدوات… الأداة الصح | كومة أدوات رمادي، وواحدة بس بتنور أخضر وتتسحب للمسار |
| نفس النتيجة اللي عجبتك كل مرة | نفس الكارت بيتطبع 3 مرات متطابق ✓✓✓ |
| تصميمات، فيديوهات، بريزنتيشن، لحد موقعك | محطات آخر المسار بتنور ورا بعض |
| محاضرات + كتيب + متابعة | المسار بيوصل لكارت الدبلومة |
| +300 + خصم + «AI» | عداد + خانة كومنت |

## C — «ليه تختارنا؟» (~65ث) — كلمة «دبلومة»

الستايل: سؤال وجواب. كل سؤال على كارت فصل كحلي كبير، والإجابة على عاجي بأمثلة شغالة. فيه لمسة هزار في الأول.

| الجملة | اللي بيترسم |
|---|---|
| كورسات الـ AI أكتر من كورسات الطبخ | مطر من ثامبنيلز كورسات (AI وطبخ متلخبطين)، وعلى «طب ليه تختار» كله يقف ويتشال |
| معمولة لشغلك انت… تتابع، تصميمات، بريزنتيشن، موقع | شاشة «يومك في الشغل» وكل استخدام بيطلع فيها كارت |
| الأداة الصح + نفس النتيجة | نفس فكرة B بس كـ before/after جنب بعض |
| طب هتتعلم ازاي؟ | كارت فصل كحلي: «هتتعلم ازاي؟» |
| محاضرات مخصوص + كتيب | محاضرة بتشتغل + كتيب بيتقلب |
| وبعد ما تخلص؟ | كارت فصل كحلي: «وبعد ما تخلص؟» |
| لايف شهري، أبديتس، أسئلتك، اشتراكات هدية | كاليندر لايف، إشعار أبديت، فقاعة سؤال، صندوق هدية بيتفتح |
| +300 جربوا قبلك | حيطة فيدباك (لو فيه سكرينشوتات حقيقية) |
| خصم + «دبلومة» | خانة كومنت |

## الأسيتس

لازم:
1. ملفات الصوت الـ 3 (WAV أو MP3) بأسماء A / B / C.

موجود عندي:
- اللوجو الرسمي من ملفات الهوية. خلفيته بيضا، فهفرّغه بنفسي، ولو عندك PNG شفاف أحسن.

بيفرق جدًا (لو موجود):
2. سكرينشوتات حقيقية من منصة الدبلومة: صفحة محاضرة، قايمة المحاضرات.
3. 2–3 صفحات من الكتيبات.
4. سكرينشوت من لايف أو جروب المتابعة (من غير أسماء أو بموافقة).
5. 5–10 سكرينشوتات فيدباك من خريجين (بموافقتهم). من غيرها مش هنعمل حيطة الفيدباك، وهنكتفي برقم +300.
6. نماذج شغل حقيقية: تصميمات، صفحة موقع، فيديو اتعمل بالـ AI.
7. مزيكا خلفية (royalty-free) لو عايز. من غيرها هعمل SFX خفيفة بس تحت الصوت.

قرارات محتاجة رد:
- نسبة الخصم أو السعر يظهر على الشاشة، ولا «خصم لفترة محدودة» من غير رقم؟
